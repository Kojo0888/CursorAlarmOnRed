# PRD — Cursor Alarm On Red

## 1. Purpose
A tiny Windows desktop tool that watches the single screen pixel under the mouse cursor and plays an alarm sound when that pixel is "red".

## 2. Users & use case
One person who needs to be alerted when the cursor is over something red (a warning indicator, a status light, a game element, etc.) without staring at it.

## 3. Functional requirements
| ID | Requirement |
|----|-------------|
| F1 | **Start** button begins monitoring the pixel under the cursor. |
| F2 | **Stop** button ends monitoring and silences the alarm. |
| F3 | While monitoring, the app shows the current **R, G, B** values (0–255) of the pixel under the cursor, plus a colour swatch. |
| F4 | Below the colour display there is a **threshold textbox** (integer 0–255). |
| F5 | Alarm rings when the pixel is red according to the rule in §4. |
| F6 | The threshold is **saved to a config file** and **loaded automatically** at next launch. |
| F7 | Invalid threshold input (not a number / out of range) is rejected visibly and never saved; the last valid value stays in effect. |
| F8 | Works across the whole screen (any window, any monitor, any DPI scaling). |

## 4. "Red" definition
There are many shades of red, so one number controls how strict the match is.

A pixel (R, G, B) is **red** when all of these hold:
1. `R >= threshold` and `R >= 1` (pure black is never red, even at threshold 0)
2. `G <= R / 2`
3. `B <= R / 2`

Rules 2 and 3 are fixed and exclude orange, yellow, pink, magenta, white and grey (which also have a high R value).
A **higher threshold** = only stronger/purer reds trigger. A **lower threshold** = darker reds trigger too.
Default threshold: **200**.

## 5. Non-functional requirements
- Windows 10/11, 64-bit and 32-bit.
- **Distribution: at most 2 files** — `CursorAlarmOnRed.exe` and `CursorAlarmOnRed.config` (the config is created on first save if absent).
- No installer, no admin rights, no internet, no extra DLLs shipped.
- Reacts within ~100 ms; CPU use negligible when idle or running.
- No bundled audio file (alarm is generated by the OS).

## 6. Config file
- Name: `CursorAlarmOnRed.config`, located next to the exe.
- Plain text, single line `Threshold=200`.
- Missing / corrupt file → default threshold 200 is used.

## 7. UI layout (top to bottom)
1. `[ Start ]  [ Stop ]`
2. `R: 255  G: 0  B: 0` + colour swatch
3. `Red threshold (0-255): [ 200 ]`
4. Status line: *Stopped* / *Monitoring* / *ALARM!*

## 8. Out of scope
Multiple colours, custom sounds, system tray, hotkeys, logging, installers, auto-update.

## 9. Acceptance criteria
- Start → hover over pure red (255,0,0) with threshold 200 → alarm sounds; move away → alarm stops.
- Hover over (255,128,0) orange → no alarm.
- Change threshold to 100, hover over (120,10,10) → alarm; at 200 → no alarm.
- Close and reopen the app → threshold box shows the last saved valid value.
- Stop → no alarm even over red.
